**LinkMass 1.0.1** for Windows 10/11 (x64) · Free for personal use

### What's new

- System-path safety net — refuses destructive operations on Windows, System32, Program Files, AppData, and drive roots; scan override for read-only browsing
- UI scale setting — Compact, Default, Comfortable, Large, and Huge presets with live preview
- Modern rubber-band drag-select in scanner — drag back to deselect, preserves prior selection state
- Help screen expanded with safety warnings and scope guidance
- Danger modal cleaned up — no dim backdrop, buttons auto-widen to fit labels
- Text layout fixes — UTF-8 safe truncation across log, scanner, and long path labels
- Scanner toolbar now wraps on narrow windows — no more buttons clipped off the edge
